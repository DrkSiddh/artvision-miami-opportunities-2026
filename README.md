# ArtVision Miami Art Week Opportunities

Narrative podcast scripts and a searchable database of free (or justified-fee) exhibition opportunities during Miami Art Week, with a focus on digital, physical, and Web3/crypto-related calls.

- `narrative_script.md` — Conversational script for the ArtVision podcast special segment (coffee-chat voice).
- `opportunities_database.md` — Structured entries searchable by keyword MIAMI + details + URL. Deadlines tracked so expired ones can be filtered.

Voice: encouraging, uplifting, never punching down. Prefer free opportunities that include actual exhibition and event access. Fees only if the opportunity is prestigious and the value is clearly explained.

Updated as new open calls are found.
