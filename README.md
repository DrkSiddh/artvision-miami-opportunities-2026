# ArtVision Miami Art Week Opportunities Database

Searchable running list of free (preferred) and select prestigious fee opportunities for artists to exhibit digital or physical work during Miami Art Week, with emphasis on Web3/crypto related.

## How to search
Look for keyword **MIAMI** in titles, notes, or location. Filter by status: open.

## Files
- narrative_script_*.md : Conversational podcast-ready scripts
- database_entries_*.json : Structured entries with deadline, fee, receipts, URL, etc.

Updated regularly for the ArtVision brand special segment. Encouraging, clear, directive.
